🔥 IMPORTANT INTERVIEW POINT

Exceptions can occur in TWO COMPLETELY DIFFERENT PLACES:

1. BEFORE Controller
   (Filters / Spring Security)

2. AFTER Controller
   (Controller / Service / Repository)

The handling mechanism is different for both.

🟥 CATEGORY 1 : EXCEPTIONS INSIDE SECURITY FILTERS
═══════════════════════════════════════════════════════════════════════════════

Examples:

JWTAuthenticationFilter
CustomSecurityFilter
UsernamePasswordAuthenticationFilter

Flow:

Client
  │
  ▼
JWT Filter
  │
  ├── ExpiredJwtException
  ├── MalformedJwtException
  ├── SignatureException
  ├── JwtException
  │
  ✘ Controller never reached

Therefore:

❌ @RestControllerAdvice may not automatically catch these

Why?

Because request has not yet reached:

DispatcherServlet
     │
     ▼
Controller

Hence Spring MVC exception handling is not active yet.

🟩 SOLUTION #1 : TRY-CATCH INSIDE FILTER
═══════════════════════════════════════════════════════════════════════════════

@Override
protected void doFilterInternal(...) {

    try {

        jwtService.validateToken(token);

        filterChain.doFilter(request,response);

    }

    catch (JwtException ex){

        response.setStatus(401);

        response.setContentType("application/json");

        response.getWriter().write("""
                {
                   "error":"Invalid JWT"
                }
                """);
    }
}

Advantages
-----------
✅ Simple

✅ Easy for beginners

✅ Direct response

Disadvantages
--------------
❌ Duplicate code

❌ Every filter writes response manually

❌ Hard to maintain



═══════════════════════════════════════════════════════════════════════════════
🟦 SOLUTION #2 : HANDLEREXCEPTIONRESOLVER
═══════════════════════════════════════════════════════════════════════════════

Flow:

JWT Filter
     │
     ├── JwtException
     │
     ▼
HandlerExceptionResolver
     │
     ▼
@RestControllerAdvice

Code:

@Component
@RequiredArgsConstructor
public class JWTAuthenticationFilter
        extends OncePerRequestFilter {

    private final HandlerExceptionResolver
            handlerExceptionResolver;

    @Override
    protected void doFilterInternal(...) {

        try {

            jwtService.validateToken(token);

            filterChain.doFilter(request,response);

        }

        catch (Exception ex){

            handlerExceptionResolver
                    .resolveException(
                            request,
                            response,
                            null,
                            ex);
        }
    }
}

Advantages
-----------

✅ Reuse GlobalExceptionHandler

✅ Single error response structure

✅ Very popular in JWT projects

✅ Clean architecture


Flow Diagram

JwtException
      │
      ▼
HandlerExceptionResolver
      │
      ▼
@RestControllerAdvice
      │
      ▼
JSON Response

🟨 SOLUTION #3 : AUTHENTICATIONENTRYPOINT
═══════════════════════════════════════════════════════════════════════════════

Spring Security's Official Way

Flow:

JWT Filter
      │
      ▼
AuthenticationException
      │
      ▼
ExceptionTranslationFilter
      │
      ▼
AuthenticationEntryPoint
      │
      ▼
401 Unauthorized

Implementation:

@Component
public class JWTAuthenticationEntryPoint
        implements AuthenticationEntryPoint {

    @Override
    public void commence(
           HttpServletRequest request,
           HttpServletResponse response,
           AuthenticationException ex)
           throws IOException {

        response.setStatus(401);

        response.getWriter()
                .write("Unauthorized");
    }
}

SecurityConfig:

http.exceptionHandling(
        ex -> ex.authenticationEntryPoint(
                jwtAuthenticationEntryPoint));

Advantages
------------

✅ Official Spring Security approach

✅ Industry standard

✅ Security layer handles security exceptions

✅ Recommended for enterprise applications

🟫 CATEGORY 4 : AUTHORIZATION EXCEPTIONS
═══════════════════════════════════════════════════════════════════════════════

Authentication
--------------
WHO ARE YOU?

Authorization
--------------
WHAT ARE YOU ALLOWED TO DO?


Example

User Role:

ROLE_USER


Trying To Access

/admin


Result:

AccessDeniedException


Flow

User Authenticated
       │
       ▼
Authorization Check
       │
       ▼
AccessDeniedException
       │
       ▼
AccessDeniedHandler


Implementation

@Component
public class JWTAccessDeniedHandler
        implements AccessDeniedHandler {

    @Override
    public void handle(
            HttpServletRequest request,
            HttpServletResponse response,
            AccessDeniedException ex)
            throws IOException {

        response.setStatus(403);

        response.getWriter()
                .write("Access Denied");
    }
}

⭐⭐⭐ INTERVIEW ONE-LINER ⭐⭐⭐

"Exceptions occurring before DispatcherServlet (Filters/Spring Security)
should be handled using AuthenticationEntryPoint, AccessDeniedHandler, or
HandlerExceptionResolver. Exceptions occurring after DispatcherServlet
(Controllers, Services, Repositories) should be handled using
@RestControllerAdvice and @ExceptionHandler."
