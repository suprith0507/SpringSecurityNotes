🎯 WHAT IS JWT?

JWT = JSON Web Token

JWT is a compact, self-contained, digitally signed token used to represent authenticated user identity and authorization information in a stateless manner.

JWT solves the biggest problem of Session Authentication:

❌ Server Memory Storage
❌ Session Replication
❌ Redis Requirement
❌ Sticky Sessions
❌ Session Lookup

JWT says:

"Do not store user information on server. Put the information inside the token itself and digitally sign it."

====================================================================================================

❌ Credit Card
❌ Secret Key

✅ UserId

⬜ SPRING BOOT JWT TOKEN CREATION
====================================================================================================

String token =
    Jwts.builder()

        .subject(username)

        .claim("role","ADMIN")

        .issuedAt(new Date())

        .expiration(
            new Date(
               System.currentTimeMillis()
               + 86400000
            )
        )

        .signWith(secretKey)

        .compact();

🟫 SPRING SECURITY CONFIGURATION
====================================================================================================

@Bean
public SecurityFilterChain security(
        HttpSecurity http)
        throws Exception {

    return http

            .csrf(csrf -> csrf.disable())

            .sessionManagement(session ->
                    session.sessionCreationPolicy(
                            SessionCreationPolicy
                                    .STATELESS
                    )
            )

            .addFilterBefore(
                    jwtFilter,
                    UsernamePasswordAuthenticationFilter.class
            )

            .build();
}

JWT

Therefore:

CSRF protection usually unnecessary.

🎯 INTERVIEW MASTER SUMMARY
====================================================================================================

✅ JWT = JSON Web Token.
✅ JWT is a Stateless Authentication mechanism.
✅ JWT consists of Header.Payload.Signature.
✅ Header describes algorithm and token type.
✅ Payload contains Claims (user data).
✅ Signature prevents tampering.
✅ JWT is signed, NOT encrypted.
✅ Never store passwords or secrets inside JWT.
✅ Spring validates JWT by verifying signature and expiry.
✅ JWT is commonly sent using:
      Authorization: Bearer <token>
✅ JWT eliminates server-side session storage.
✅ JWT works well with Angular, React, Mobile Apps and Microservices.
✅ Access Token authenticates requests.
✅ Refresh Token obtains new Access Tokens.
✅ Spring implements JWT using a custom JwtAuthenticationFilter or OAuth2 Resource Server support.
✅ Session Authentication is Stateful.
✅ JWT Authentication is Stateless.
✅ Modern cloud-native applications generally prefer JWT because no session replication or server memory storage is required.
