        HttpSecurity http)
        throws Exception {

    return http

            .headers(headers ->

====================================================================================================
🎯 INTERVIEW MASTER ANSWER
====================================================================================================

JWT token theft is primarily caused by XSS attacks, not by the absence of CSRF protection. If an attacker executes JavaScript inside the trusted application's origin, the script can read JWTs stored in localStorage, sessionStorage, or accessible cookies and send them to an attacker-controlled server.

Traditional CSRF attacks do not normally steal JWTs because JWT-based systems usually transmit tokens using the Authorization header, which browsers do not automatically attach to cross-site requests.

To prevent JWT theft:

✅ Prevent XSS using input validation, output encoding, sanitization and Content Security Policy.
✅ Prefer HttpOnly cookies for sensitive tokens.
✅ Use Secure and SameSite cookie attributes.
✅ Use short-lived Access Tokens.
✅ Use Refresh Tokens with rotation.
✅ Avoid storing long-lived JWTs in localStorage for high-security applications.
