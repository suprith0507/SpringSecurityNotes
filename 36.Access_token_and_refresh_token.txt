🎯 INTERVIEW MASTER ANSWER
====================================================================================================

Access Tokens are short-lived JWTs used to authenticate and authorize API requests. They typically contain user identity and roles and are sent in the Authorization header. Because they have short expiration times, the impact of token theft is reduced.

Refresh Tokens are long-lived credentials used only to obtain new Access Tokens after the Access Token expires. They are not used to access business APIs directly. Modern applications often store Refresh Tokens in HttpOnly Secure cookies and implement Refresh Token Rotation to prevent replay attacks.

The most secure enterprise architecture is:

Login
   ↓
Access Token (15 Minutes)
   ↓
Refresh Token (7 Days)
   ↓
Access Token Expires
   ↓
Refresh Token Generates New Access Token
   ↓
User Continues Without Re-Login
