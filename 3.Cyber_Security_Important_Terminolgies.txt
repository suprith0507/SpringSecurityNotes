Every secure system ultimately asks:

1. Who are you?
2. How do I verify that?
3. What are you allowed to do?
4. How do I prove what you did?
5. How do I protect the data?

Everything in security exists to answer these questions.

🎬 CHAPTER 4 : MULTI FACTOR AUTHENTICATION (MFA)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Password Alone:

┌───────────────┐
│ Password      │
└───────────────┘

Single Layer.

MFA:

┌───────────────┐→┌───────────────┐
│ Password      │ │ OTP/Fingerprint│
└───────────────┘ └───────────────┘

Two Layers.

Even if password leaks:

Attacker still needs second factor.

This dramatically reduces account takeover risk.

✅ Actions can be traced back to users.

Without logs:

User Deletes Data

Nobody Knows Who Did It.

Problem.

With logs:

User Deletes Data
        │
        ▼
Audit Log Generated
        │
        ▼
Evidence Exists

✅ Audit Logging
✅ Security Logging
✅ SIEM Systems

Repudiation Means:

❌ "I didn't do it."

Non-Repudiation Means:

✅ User Cannot Deny Action.

Example:

Digital Banking Transfer

User Signs Transaction

System Stores Evidence

Later:

User Claims

"I never transferred money."

Evidence Exists.

Non-Repudiation Ensures:

✅ Traceability
✅ Proof
✅ Legal Validity

Never Trust One Protection Layer.

Only One Layer.

╔══════╗→╔════════╗→╔══════╗→╔════════╗→╔═══════╗→╔══════╗
║ DNS  ║ ║Firewall║ ║ WAF  ║ ║ Gateway║ ║Security║ ║ DB   ║

If One Layer Fails,
Others Remain.

This is defense-in-depth.
