🎯 BEFORE LEARNING ANY CLASSES, UNDERSTAND THE MAIN GOAL

Spring Security exists to answer ONLY TWO QUESTIONS:

🟢 Authentication ➜ WHO ARE YOU?
🟢 Authorization  ➜ WHAT ARE YOU ALLOWED TO ACCESS?

Everything inside Spring Security exists only to achieve these two goals.

🎯 GOLDEN INTERVIEW SUMMARY:

Spring Security is fundamentally a filter-based framework. Every request first enters DelegatingFilterProxy, then FilterChainProxy, which executes a SecurityFilterChain containing multiple security filters. Authentication is performed using AuthenticationManager → AuthenticationProvider → UserDetailsService → PasswordEncoder. Once authenticated, the user is stored inside SecurityContextHolder. Authorization then checks user roles and authorities through AuthorizationFilter and AuthorizationManager. Only after successful authentication and authorization is the request allowed to reach the Controller.
